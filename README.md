# Fraud Detection & Risk Analysis Using SQL

## Project Overview
This project focuses on analyzing and detecting fraudulent transaction patterns using SQL on a large-scale transaction dataset. The project simulates real-world fraud investigation workflows used in fintech, banking, and e-commerce systems by applying behavioral analysis, transaction monitoring, and rule-based risk detection techniques.

---

## Project Objectives
- Analyze fraudulent transaction behavior using SQL
- Detect suspicious user and transaction patterns
- Perform time-based and behavioral fraud analysis
- Identify high-risk transactions using analytical SQL queries
- Simulate real-world fraud detection workflows
- Build a rule-based fraud risk scoring system
- Strengthen practical SQL and data analysis skills using real transactional data
